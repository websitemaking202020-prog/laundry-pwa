│                            DATA FLOW EXAMPLES                               │
└─────────────────────────────────────────────────────────────────────────────┘

📱 CUSTOMER BOOKS SERVICE
─────────────────────────
Customer → Fill Form → Submit
    ↓
Supabase → Create Order Record
    ↓
Real-time → Notify Admin Dashboard
    ↓
OneSignal → Push Notification to Admin
    ↓
Admin sees new order instantly!


👤 ADMIN ASSIGNS TASK
─────────────────────
Admin → Select Order → Choose Staff → Assign
    ↓
Supabase → Update order.assigned_to
    ↓
Real-time → Update Staff Dashboard
    ↓
OneSignal → Push Notification to Staff
    ↓
Staff sees new task instantly!


✅ STAFF COMPLETES ORDER
────────────────────────
Staff → Mark Complete
    ↓
Supabase → Update order.status = 'completed'
    ↓
Real-time → Update Customer Dashboard
    ↓
OneSignal → Push "Ready for Pickup!" to Customer
    ↓
Customer gets notification!

└─────────────────────────────────────────────────────────────────────────────┘

ROW LEVEL SECURITY (RLS) POLICIES:
───────────────────────────────────
✓ Customers see only their own orders
✓ Staff see only assigned tasks
✓ Admin sees everything
✓ All enforced at database level

AUTHENTICATION:
───────────────
✓ Email/Password via Supabase Auth
✓ Secure password hashing (bcrypt)
✓ JWT tokens for sessions
✓ Automatic session refresh

BOT PROTECTION:
───────────────
✓ Cloudflare Turnstile on login
✓ Invisible challenge for real users
✓ Blocks automated attacks

┌─────────────────────────────────────────────────────────────────────────────┐
│                         SETUP FLOW                                          │
└─────────────────────────────────────────────────────────────────────────────┘

1. Setup Supabase       → Create project, run SQL schema
2. Setup OneSignal      → Create app, get App ID
3. Setup Turnstile      → Get site key
4. Configure API Keys   → Edit js/config.js
5. Create Admin User    → Register + SQL update
6. Deploy/Test          → Run locally or deploy to cloud
7. Start Using!         → Book orders, assign tasks, complete

TOTAL SETUP TIME: ~15-20 minutes
