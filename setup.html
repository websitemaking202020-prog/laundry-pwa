🧺 LaundryLink Setup Guide

Get your laundry management system up and running in minutes

📋 Quick Setup Checklist

  • Create Supabase account and project
  • Set up database schema
  • Create OneSignal account for notifications
  • Set up Cloudflare Turnstile
  • Configure API keys
  • Create admin user
  • Deploy or test locally

1️⃣ Supabase Setup

1Create Account

Go to supabase.com and create a free account.

2Create New Project

  • Click "New Project"
  • Choose a name (e.g., "laundrylink")
  • Set a strong database password (save it!)
  • Select a region closest to you
  • Wait for project to finish setting up (~2 minutes)

3Run Database Schema

  • Go to SQL Editor in the left sidebar
  • Click "New Query"
  • Copy the entire contents of supabase-schema.sql
  • Paste into the editor
  • Click "Run" (bottom right)
✓ Success! You should see "Success. No rows returned" - this is normal.

4Enable Email Authentication

  • Go to Authentication → Providers
  • Ensure "Email" is enabled (it should be by default)
  • Optional: Disable "Confirm email" for testing (enable in production)

5Get API Keys

  • Go to Settings → API
  • Copy Project URL
  • Copy anon public key
  • Save these for later!

6Enable Realtime (Optional but Recommended)

  • Go to Database → Replication
  • Enable replication for the orders table
  • This enables real-time updates across all dashboards

2️⃣ OneSignal Setup

1Create Account

Go to onesignal.com and sign up for free.

2Create New App

  • Click "New App/Website"
  • Enter app name: "LaundryLink"
  • Select "Web Push" platform

3Configure Web Push

  • Choose "Typical Site" configuration
  • Enter your site URL (or use localhost:8000 for testing)
  • Upload an icon (optional) or use default
  • Complete the setup wizard

4Get App ID

  • After setup, go to Settings → Keys & IDs
  • Copy your App ID
  • Save it for later!

3️⃣ Cloudflare Turnstile Setup

1Access Turnstile

Go to Cloudflare Dashboard (create account if needed)

2Create Site

  • Navigate to Turnstile in the sidebar
  • Click "Add Site"
  • Enter site name: "LaundryLink"
  • Add domain (or use localhost for testing)
  • Choose widget mode: Managed (recommended)
  • Click "Create"

3Get Site Key

  • Copy the Site Key
  • Save it for configuration!
Note: For testing, you can use the test site key: 1x00000000000000000000AA (always passes)

4️⃣ Configure API Keys

1Open Config File

Open js/config.js in your text editor

2Replace Placeholder Values

const CONFIG = {
    supabase: {
        url: 'YOUR_SUPABASE_URL',        // Paste your Supabase URL here
        anonKey: 'YOUR_SUPABASE_ANON_KEY' // Paste your anon key here
    },
    oneSignal: {
        appId: 'YOUR_ONESIGNAL_APP_ID'    // Paste your OneSignal App ID here
    },
    turnstile: {
        siteKey: 'YOUR_TURNSTILE_SITE_KEY' // Paste your Turnstile site key here
    }
};

3Save the File

Save and close the file.

5️⃣ Create Admin User

1Start the App

Run a local server (see deployment section below)

2Register First User

  • Click "Create Account"
  • Fill in your details
  • Register as customer

3Promote to Admin

  • Go to Supabase Dashboard → Authentication → Users
  • Copy your user ID (UUID)
  • Go to SQL Editor
  • Run this query:
update profiles
set role = 'admin'
where id = 'YOUR-USER-UUID-HERE';

4Log Out and Log In

You should now see the Admin Dashboard!

6️⃣ Deployment Options

Option 1: Local Testing

Using Python:

python -m http.server 8000

Then visit: http://localhost:8000

Using Node.js:

npx serve .

Option 2: Deploy to Netlify (Recommended)

  1. Push your code to GitHub
  2. Go to netlify.com
  3. Click "Add new site" → "Import an existing project"
  4. Connect your GitHub repository
  5. No build settings needed - just deploy!
  6. Your app will be live at your-site.netlify.app

Option 3: Deploy to Vercel

  1. Push your code to GitHub
  2. Go to vercel.com
  3. Click "New Project"
  4. Import your GitHub repository
  5. Deploy!

7️⃣ Testing the App

Test the Complete Flow:

  1. Customer: Register → Book a service → Check order status
  2. Admin: View new order → Add staff member → Assign order to staff
  3. Staff: Log in with staff credentials → View assigned task → Mark complete
  4. Customer: Receive notification → Check completed order

🎨 Customization Tips

Change Colors

Edit css/styles.css - look for CSS variables in :root

Update Pricing

Edit js/config.js - modify SERVICE_PRICING

Add/Remove Services

Update both js/config.js and the select dropdown in index.html

Change Branding

  • Update app name in index.html and manifest.json
  • Replace icons in img/ folder (create 192x192 and 512x512 PNG files)

🐛 Troubleshooting

Can't log in?

  • Check Supabase credentials in config.js
  • Verify email confirmation is disabled in Supabase Auth settings
  • Check browser console for errors (F12)

Push notifications not working?

  • Must use HTTPS (or localhost for testing)
  • Check OneSignal App ID is correct
  • Grant browser permission when prompted

Turnstile not showing?

  • Verify site key is correct
  • Try using test key for local testing
  • Disable adblockers

Database errors?

  • Ensure schema was run completely
  • Check Row Level Security policies are enabled
  • Verify user role in profiles table
