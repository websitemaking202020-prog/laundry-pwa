📋 SETUP CHECKLIST
──────────────────
□ 1. Create Supabase account → Run supabase-schema.sql
□ 2. Create OneSignal account → Get App ID
□ 3. Create Cloudflare Turnstile → Get Site Key
□ 4. Update js/config.js with all API keys
□ 5. Start server: ./start.ps1 or python -m http.server 8000
□ 6. Register first user → Make admin in Supabase
□ 7. Test: Book order → Assign to staff → Complete

🔑 FIRST ADMIN USER
───────────────────
1. Register through the app
2. Copy UUID from Supabase > Authentication > Users
3. Run in SQL Editor:
   update profiles set role = 'admin' where id = 'YOUR-UUID';
4. Logout and login again

🐛 TROUBLESHOOTING
──────────────────
Can't login?
  → Check Supabase URL & key in config.js
  → Disable email confirmation in Supabase

No notifications?
  → Must use HTTPS (or localhost)
  → Check OneSignal App ID
  → Grant browser permission

Turnstile not showing?
  → Use test key: 1x00000000000000000000AA
  → Disable adblockers

Database errors?
  → Re-run supabase-schema.sql completely
  → Check user role in profiles table
